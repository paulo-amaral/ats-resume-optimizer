# Lista de linguagem genérica (PT-BR)

Rode esta revisão em todo rascunho. `ats-resume check` sinaliza os termos abaixo
(a lista completa fica em `src/ats_resume/checks.py`).

## Verbos inflados

| Evite | Use |
|---|---|
| Alavanquei | Aumentei (com número) / Usei |
| Capitaneei | Liderei |
| Orquestrei | Coordenei |
| Potencializei | Aumentei (com número) |
| Fomentei | Incentivei / Criei |

## Clichês de perfil

Proativo(a), dinâmico(a), apaixonado(a), focado(a) em resultados, orientado(a) a
resultados, sinergia, pensar fora da caixa. Corte e prove com um fato:
"proativo" → "Propus e implantei o checklist de deploy que zerou rollbacks em 3 meses".

## Enchimento

| Evite | Use |
|---|---|
| Responsável por / encarregado de | Comece com um verbo de ação |
| Auxiliei / ajudei / participei | Diga qual foi exatamente a sua parte |
| Com sucesso | Remova; mostre o resultado |
| A fim de / com o objetivo de | Para |
| Diversos(as) | Cite quais, ou remova |
| No dia a dia | Diariamente |

## Pontuação

Evite travessão (—) como muleta de estilo. Use vírgula, ponto ou "para".
