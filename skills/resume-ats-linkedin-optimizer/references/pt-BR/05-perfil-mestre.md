# O Perfil Mestre (fonte única da verdade)

O Perfil Mestre é um **registro privado e completo de tudo o que a pessoa já fez**:
cada função, bullet, métrica, competência, ferramenta, projeto e credencial. Cada
variante de currículo e de LinkedIn é uma **seleção e reformulação** dessa base, nunca
uma invenção em cima dela.

> Tradução de `../05-master-profile.md`. Em caso de divergência, vale o original em inglês.

## Por que ele existe

- **Veracidade.** Se um fato não está no Perfil Mestre, não vai para o currículo. É a
  aplicação mecânica da regra de zero invenção.
- **Velocidade.** Adaptar vira *escolher quais fatos verdadeiros mostrar*, em vez de
  escrever do zero a cada vez.
- **Consistência.** Toda variante remete aos mesmos fatos, então datas, cargos e
  métricas não divergem entre versões.
- **Em lote.** N candidaturas = N seleções de uma única base.

## Como montar

1. Reúna tudo o que a pessoa tem: currículo(s), exportação do LinkedIn, registros de
   conquistas, avaliações de desempenho, descrições de cargos antigos. Para um PDF ou
   DOCX existente, `ats-resume import cv.pdf` gera um esqueleto com o texto bruto de cada
   seção.
2. Preencha `assets/master-profile-template.md`, registrando *mais* do que qualquer
   currículo isolado mostraria (bullets extras, competências secundárias, projetos
   paralelos).
3. Faça a **Escavação de Métricas** (Fase 1): para cada função, faça as perguntas
   direcionadas para revelar números reais, confirmados pela pessoa, e guarde-os aqui. Os
   números ficam no Perfil Mestre uma vez e depois alimentam todas as variantes.
4. Mantenha atualizado: antes de cada sessão de adaptação, acrescente o que for novo.

## O sistema de visibilidade

Marque cada função/bullet para que a seleção seja rápida e intencional:

- `always`: essencial para a identidade profissional; aparece em praticamente todo
  currículo.
- `variant-specific`: só para certos cargos/setores-alvo.
- `on-request`: só se a vaga ou a pessoa pedir.
- `reference-only`: nunca aparece como está (contexto, notas pessoais, métricas brutas
  de consulta).

Ao adaptar, registre também uma nota **"Excluído desta variante, e por quê"**: isso
deixa revisões e lotes de várias vagas coerentes e evita perder algo importante por
engano.

## Relação com os resultados

```
Perfil Mestre (todos os fatos verdadeiros, completo)
        │  selecionar + reformular (nunca inventar)
        ├── Variante de currículo A  (adaptada à Vaga A, segura para ATS, 1–2 páginas)
        ├── Variante de currículo B  (adaptada à Vaga B)
        └── Perfil do LinkedIn       (superconjunto, tom de conversa, sempre atual)
```

O Perfil Mestre pode guardar tudo; cada resultado é um subconjunto curado, moldado
pelo objetivo e pelas regras do meio (`01`–`04`).
